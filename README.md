**VitaLog** ist eine moderne, hochgradig interaktive Lebenssimulation im Browser, inspiriert von Spielen wie *BitLife*, jedoch mit einem eigenständigen Dark-Mode-Design, einer tiefen Wirtschaftssimulation, prozeduralen Ereignissen und Mehrgenerationen-Dynastien. Begleite deinen Charakter von der Geburt bis zur Rente – und führe dein Erbe als nächste Generation weiter!

---

## ✨ Hauptfunktionen & Highlights

### 👶 1. Charaktererstellung & DNA-Generator
- **10 Geburtsländer:** Deutschland, USA, Schweiz, Österreich, Japan, England, Frankreich, Brasilien, Australien, Spanien/Kanaren – jedes Land besitzt individuelle Steuersätze, Währungen (€, $, £, ¥), Gehaltsfaktoren und Bildungsstandards.
- **7 Startbedingungen:** Von *Mittelschicht* über *Reiche Eltern*, *Waisenhaus*, *Überdurchschnittlich begabt (Genie)*, *Athletik-Genetiker*, *Chronisch krank* bis hin zum *Adelsgeschlecht* (+500.000 € Startgeld!).
- **8 Dynamische Attribute (0-100%):** Gesundheit, Glück, Intelligenz, Aussehen, Disziplin, Stress, Energie und Karma.

### ⏳ 2. Das Leben ("Ein Jahr älter werden"-Engine)
- Jeder Klick auf den großen **Ein Jahr älter werden**-Button treibt die Simulation voran.
- **Lebenschronik (Logbuch):** Alle Ereignisse des Jahres werden übersichtlich mit Zeitstempel protokolliert und können nach Meilensteinen, Erfolgen und Rückschlägen gefiltert werden.
- **Prozedurales & Statisches Event-System:** Über **300+ Ereignis-Variationen** aus 11 Kategorien (*Schule, Familie, Liebe, Gesundheit, Karriere, Finanzen, Freizeit, Glück, Unglück, Kriminalität, Haustiere*). Jedes Ereignis bietet mehrere Auswahlmöglichkeiten mit echten Konsequenzen für Werte und Kontostand!

### 🎓 3. Bildungssystem & Karrieredynamik
- **Bildungsweg:** Kindergarten ➔ Grundschule ➔ Mittelschule / Gymnasium ➔ Berufsausbildung / Universitätsstudium (10 Fachrichtungen wie Informatik, Medizin, Jura, BWL) ➔ Promotion (Doktortitel).
- **Stellenbörse mit 35+ Berufen:**
  - *Tech & Wissenschaft:* Software-Entwickler, CTO, Astronaut, NASA-Kommandant, Forscher, Nobelpreisträger, Cyber-Security Hacker.
  - *Wirtschaft & Recht:* Investmentbanker, Bankdirektor, Start-up Gründer, Globaler Tycoon, Rechtsanwalt, Bundesrichter.
  - *Medizin & Pflege:* Assistenzarzt, Chirurg, Chefarzt, Psychologe, Tierarzt, Krankenschwester.
  - *Medien, Kunst & Sport:* Hollywood-Schauspieler, Popstar, Influencer, Modedesigner, Star-Architekt, Profisportler, Weltmeister.
  - *Öffentlicher Dienst & Handwerk:* Polizeipräsident, Bundeskanzler/Präsident, General, Handwerksmeister, 3-Sterne-Koch, Immobilienmakler.
- **Aktionen im Job:** Nach Gehaltserhöhung verhandeln, Überstunden leisten, Kündigen oder ab 60 Jahren in den Ruhestand mit garantierter Rente gehen.

### 💰 4. Finanzen, Aktienmarkt & Glücksspiel
- **Vermögensbilanz:** Echtzeit-Berechnung von Bankkonto, Nettovermögen, jährlichen Einnahmen, Lebenshaltungskosten und Steuern.
- **Bankkredite:** Kredite aufnehmen, Sondertilgungen leisten und Zinsen verwalten.
- **Aktien- und Krypto-Börse:** Investiere in solide Aktien, physisches Gold, Immobilienfonds oder hochvolatile Kryptowährungen (*MoonDoge / Bitcoin*).
- **Glücksspiel-Lounge:** Kaufe Sofort-Rubbellose (bis zu 100.000 € Gewinn) oder spiele am Casino-Roulette-Tisch auf Rot, Schwarz oder Grün!

### 🏠 5. Immobilienmarkt & Fuhrpark
- **Immobilien (10 Objekte):** Vom WG-Zimmer im Studentenviertel über Einfamilienhäuser und Hollywood-Villen bis zum historischen Königsschloss oder der Privatinsel im Pazifik (75 Mio. €).
  - *Funktionen:* Einziehen (Wohnsitz), Renovieren/Sanieren, Verkaufen oder als Passives Einkommen vermieten!
- **Fahrzeuge (10 Modelle):** City-Fahrrad, E-Bike, Vespa-Roller, Elektro-SUV, Porsche 911, V12 Super-Sportwagen, Luxus-Yacht und Interkontinental-Privatjet.
  - *Funktionen:* Ausfahrten machen (+Glück, -Stress), jährliche Wartung durchführen oder verkaufen.

### 👨‍👩‍👧‍👦 6. Beziehungen, Haustiere & Dynastie
- **Familie & Freunde:** Interagiere mit Eltern, Geschwistern, Partnern und Kindern (Unterhalten, Geschenke machen, Streiten, um Geld bitten).
- **Romantik & Nachwuchs:** Partnersuche über Dating-App, Heiratsantrag, Traumhochzeiten feiern und eigene Kinder bekommen.
- **Tierheim:** Adoptiere 7 verschiedene Tierarten (Golden Retriever, Perserkatze, Papagei, Pferd oder sogar einen exotischen Bengaltiger!).
- **👑 Generationen-Erbe (Dynastie):** Wenn dein Charakter stirbt, kannst du als dein Kind (nächste Generation) weiterspielen und 75% des Familienvermögens erben!

### 🦹 7. Kriminalität & Gefängnissystem
- **Illegale Coups:** Ladendiebstahl, Taschendiebstahl, Steuerhinterziehung und Banken-Hacking.
- **Einbruch-Minispiel:** Knacke die Kombinationen von Spätis, Reichensiedlungen, Juwelieren und dem Zentralbank-Tresorraum!
- **Gefängnis:** Bei Verhaftung droht mehrjährige Haft. Nutze deine Zeit oder wage einen gefährlichen Gefängnisausbruch!

### 🏥 8. Gesundheit, Arzt & Wellness
- Behandlung von Krankheiten (z.B. Grippe, Burnout, Asthma) und Verletzungen.
- Besuche beim Allgemeinarzt, Facharzt, Psychotherapeuten, Fitnessstudio oder Entspannung im Wellness-Urlaub.

### 🏆 9. 50+ Erfolge (Achievements) & Statistik
- Über 50 freischaltbare Trophäen in den Kategorien *Wohlstand, Alter & Leben, Familie, Karriere, Kriminalität und Dynastie*.
- Konfetti-Animation bei freigeschalteten Meilensteinen!
- **Multi-Life-Statistik:** Verfolge über alle gespielten Leben hinweg dein höchstes Vermögen, gelebte Jahrtausende und den Stammbaum deiner Dynastie.

### ⚙️ 10. Sound-Engine & Zweisprachigkeit
- **Web Audio API Synth:** Kristallklare Soundeffekte (Klicks, Altern, Münzen, Trophäen-Fanfare, Todesglocke) – komplett ohne externe MP3-Dateien!
- **Zweisprachig (DE / EN):** Nahtloser Wechsel zwischen Deutsch und Englisch zur Laufzeit.

## 🛠️ Technischer Stack

- **Frontend:** React 19 + TypeScript
- **Build-Tool:** Vite (Extrem schnelle Builds & HMR)
- **Styling:** Tailwind CSS v4 (Glassmorphic Dark Mode Design)
- **Icons:** Lucide React
- **Effekte:** Canvas-Confetti & Web Audio API
- **Speicherung:** 100% Clientseitig über `localStorage` (keine Datenbank oder Backend nötig!)

## 🚀 Lokale Installation & Start

1. **Repository klonen oder herunterladen:**
   ```bash
   git clone https://github.com/DEIN-USER/vitalog-lifesim.git
   cd vitalog-lifesim
   ```

2. **Abhängigkeiten installieren:**
   ```bash
   npm install
   ```

3. **Entwicklungsserver starten:**
   ```bash
   npm run dev
   ```
   Öffne den im Terminal angezeigten Link (Standard: `http://localhost:5173`) in deinem Webbrowser.

4. **Für Produktion bauen:**
   ```bash
   npm run build
   ```
   Die fertigen, optimierten Dateien befinden sich anschließend im `dist/`-Ordner.

## 🌐 GitHub Pages Deployment

Das Projekt ist ab Werk vollständig für **GitHub Pages** konfiguriert (`base: './'` in `vite.config.ts`). Es gibt zwei Wege für das Deployment:

### Methode A: Automatisches Deployment per GitHub Actions (Empfohlen)

Das Repository enthält eine vorgefertigte Workflow-Datei unter `.github/workflows/deploy.yml`.

1. Lade deinen Code auf GitHub hoch (Pushen auf den Branch `main` oder `master`).
2. Gehe in deinem GitHub-Repository zu **Settings ➔ Pages**.
3. Wähle unter **Source** die Option **"GitHub Actions"** aus.
4. Sobald du Änderungen auf `main` pushst, baut GitHub die Seite automatisch und veröffentlicht sie live!

### Methode B: Manuelles Deployment (gh-pages)

Falls du das klassische `gh-pages` Paket verwenden möchtest:
1. Installiere `gh-pages` als Dev-Dependency:
   ```bash
   npm install -D gh-pages
   ```
2. Füge in deiner `package.json` unter `"scripts"` hinzu:
   ```json
   "deploy": "npm run build && gh-pages -d dist"
   ```
3. Führe `npm run deploy` aus.

## 💾 Spielstände verwalten (JSON Export / Import)

Du kannst deinen Fortschritt jederzeit sichern und auf andere Geräte übertragen:
1. Klicke im Spiel oben rechts auf das **Zahnrad-Symbol (Einstellungen)**.
2. Wähle **"Spielstand als JSON exportieren"**, um eine Sicherungsdatei herunterzuladen.
3. Auf einem anderen Gerät kannst du diese Datei über **"JSON-Spielstand importieren"** hochladen, um genau dort weiterzuspielen, wo du aufgehört hast!
